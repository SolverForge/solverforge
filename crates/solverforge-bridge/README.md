# solverforge-bridge

Dynamic model contracts for host-language SolverForge bindings, such as solverforge-py: logical model identity, dynamic variable slots and host-provider contracts.

Applications depend on the [`solverforge`](https://crates.io/crates/solverforge) facade crate, which re-exports this crate's supported items; use this crate directly only to build an integration on it. API documentation is on [docs.rs](https://docs.rs/solverforge-bridge), and the project guide is at [solverforge.org](https://solverforge.org) and in the [repository](https://github.com/SolverForge/solverforge).
