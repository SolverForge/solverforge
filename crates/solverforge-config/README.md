# solverforge-config

The `solver.toml` configuration model for SolverForge: termination, phases, move selectors, acceptors and foragers, parsed with unknown keys rejected.

Applications depend on the [`solverforge`](https://crates.io/crates/solverforge) facade crate, which re-exports this crate's supported items; use this crate directly only to build an integration on it. API documentation is on [docs.rs](https://docs.rs/solverforge-config), and the project guide is at [solverforge.org](https://solverforge.org) and in the [repository](https://github.com/SolverForge/solverforge).
