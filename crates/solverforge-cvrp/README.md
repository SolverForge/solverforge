# solverforge-cvrp

Capacitated vehicle routing helpers for SolverForge: problem data, matrix distance meters, the `VrpSolution` trait and the hooks behind `#[planning_list_variable(domain = "cvrp")]`.

Applications depend on the [`solverforge`](https://crates.io/crates/solverforge) facade crate, which re-exports this crate's supported items; use this crate directly only to build an integration on it. API documentation is on [docs.rs](https://docs.rs/solverforge-cvrp), and the project guide is at [solverforge.org](https://solverforge.org) and in the [repository](https://github.com/SolverForge/solverforge).
