# solverforge-macros

Procedural macros for SolverForge domain models: `planning_model!`, `#[planning_solution]`, `#[planning_entity]`, `#[problem_fact]` and `#[solverforge_constraints]`.

Applications depend on the [`solverforge`](https://crates.io/crates/solverforge) facade crate, which re-exports this crate's supported items; use this crate directly only to build an integration on it. API documentation is on [docs.rs](https://docs.rs/solverforge-macros), and the project guide is at [solverforge.org](https://solverforge.org) and in the [repository](https://github.com/SolverForge/solverforge).
